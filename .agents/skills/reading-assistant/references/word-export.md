# Word 导出与检查

在创建阅读整理 Word 时读取本参考。排版、操作标记和工具使用以当前 `documents:documents` 技能为准，本参考只补充读书助手的内容映射和曾出现的中文预览问题。

## 内容映射

使用 Word 的 Title 样式设置“书名 阅读整理”，在标题下标出生成日期和阅读范围。七部分使用 Heading 1，子主题使用 Heading 2。保留已生成内容的事实、限定条件、人物表、章节表和阅读问题，避免导出时压缩或漏项。

使用 `python-docx` 或文档技能推荐的可编辑生成方式，设置支持中文的字体。列表与表格分别建立为真正的 Word 段落、列表和表格。重要来源转为正文编号引注，参考资料使用真实超链接；不把 Markdown 标记或工具内部引用标记写入正文。

表格设置合理列宽、自动行高与单元格留白，跨页重复表头，避免拆开单行。标题与后续内容保持同页；参考资料较短时可整体保留在一页。多页文档可加页码。

通过 `mcp__codex_app__load_workspace_dependencies` 获得当前捆绑 Python、Node 和 LibreOffice 路径；使用文档技能中的操作标记及 `render_docx.py`。路径应在本次运行中解析，避免把版本目录、某次临时目录或用户工作区写死。

## 中文预览缺字的修复

只有渲染确实出现中文空白、方框或缺字时才排查字体。此问题可能来自渲染器的字体配置，即使系统已经安装了中文字体，预览也可能无法读取它们。

1. 检查 Word 的字体设置和字体文件是否存在。在 macOS 上可检查 `/System/Library/Fonts/Hiragino Sans GB.ttc`，也可使用当前环境已有的其他中文字体。
2. 必要时创建任务临时字体目录，将需要的中文及拉丁字体用 `shutil.copyfile` 复制进去。macOS 系统字体的受保护元数据可能使 `shutil.copy2` 失败，应只复制字体内容。
3. 在任务临时目录建立局部 Fontconfig 配置，设置 `<dir>` 指向临时字体目录、`<cachedir>` 指向任务字体缓存目录。通过仅作用于此次渲染命令的 `FONTCONFIG_FILE` 环境变量使用该配置；保持用户全局字体配置不变。
4. 继续使用依赖加载工具返回的捆绑 LibreOffice，重新执行文档技能的渲染脚本。查看所有生成的页面，确认中文、加粗、表格与换页均正常。

## 交付检查

- 文件是真正可打开的 `.docx`，不是修改扩展名的纯文本或 PDF。
- 标题、七个部分、人物或观点总结、全书章节范围、阅读思考均完整。
- 参考资料链接可用，解释和学术争议仍保留必要限定。
- 文件名符合 `书名_阅读整理_YYYYMMDD.docx`，位于当前工作区或用户指定目录。
- 最终使用绝对路径交付 Word；渲染 PNG、QA PDF 和构建脚本只留在临时目录。
