# 读书助手

将一本书整理成中文阅读笔记，并完成可编辑的 Word 文档。面向希望了解全书、梳理章节或写读后感的读者。界面名称为“读书助手”，调用标识为 `$reading-assistant`。

## 输入与默认行为

- 用户提供书名时，围绕该书整理；附带作者、译者、版本、受众或篇幅要求时一并采用。
- 用户说“随机一本”时，自行选一本资料可核实、适合完整梳理的书，先告知所选书名和作者，然后继续完成整理及 Word 文件。
- 仅给书名且书籍明确时，直接开始。未指定版本则采用通行完整版，在阅读笔记开头交代版本范围；默认包含结局。只有同名作品无法判断或版本差异会实质影响任务时，才请求必要信息。
- 已有本次对话中生成的阅读整理内容，而用户要求保存或导出时，直接完整复用已有内容、表格和来源链接。
- 默认同时完成内容整理和 Word 保存。用户明确只要聊天内容、仅要提纲、无剧透或指定其他格式时，按其要求调整。

## 核实资料

核实作者、出版或成书时间、版本、作品结构与关键回目。优先使用原著、出版社、图书馆、作者官方网站、可信学术资料；利用现有可信来源，避免重复查询。

将事实、学术争议和阅读解读区分清楚。作者归属或年代有争议时使用“通常署名”“约”“存在争议”等准确表述。原著与影视改编的情节分别处理。无法核实的出版社、页数、章节名和引文不作补写。

保留实际支持重要事实的来源。在聊天中使用可点击的来源链接；在 Word 中转换成普通编号引注与可点击的参考资料列表。未经查证的网络内容不能充当确定结论。

## 七部分内容

按下列顺序组织，篇幅根据作品长度、复杂程度及用户用途决定。

| 部分 | 应包含的内容 |
| --- | --- |
| 书籍基本信息 | 书名、作者、时代或首次出版时间、文学类型、作品地位、所用版本及结构；版本明确时再列出版社、译者等信息 |
| 作者介绍 | 作者身份、主要经历、代表作品及与本书有关的文学特点；保留作者归属的必要说明 |
| 创作背景 | 历史社会背景、作品形成或出版背景、文化思想环境；文学解读不能替代已知史实 |
| 故事概括 | 按起因、发展、转折和结局梳理主线，清楚说明主要人物与冲突 |
| 内容总结 | 主要主题、人物特点及矛盾、重要观点和表达方式，与情节概述形成不同层次 |
| 章节分析 | 依据真实目录或回目梳理全书，标出章节范围、主要内容和分析重点，再选择有代表性的章节精读 |
| 阅读思考 | 提出能结合原文讨论的问题，给出思考方向，并提供写读后感的方法 |

非虚构作品的“故事概括”改为全书论述或叙事主线；“内容总结”着重核心论点、证据及适用条件。散文集、诗集等按真实篇目、主题或分辑分析，避免虚构连续剧情。

长篇作品可按连续阶段合并章节，但必须覆盖全书，并明确这是阶段分析。用户要求逐章分析时，逐章完成。人物或章节适合比较时使用表格；详细解释保留为段落。阅读思考默认提供约五个问题，用户指定数量时优先采用。

## Word 命名与保存

首次输出统一命名为：

```text
书名_阅读整理_YYYYMMDD.docx
```

- 书名不带外层《》；保留能够辨认作品的完整书名。
- 日期使用本次生成时用户当地日期。优先采用会话的当前日期与时区，不能沿用示例日期。
- 将文件名中的路径分隔符和 `\\ / : * ? " < > |` 等不兼容字符替换为下划线，去除首尾空白，保证输出仍是单个文件。
- 保存到当前任务工作区的根目录，使用其绝对路径。用户明确指定目录或文件名时采用用户指定值。
- 同名文件已存在且未授权覆盖时，依次使用 `书名_阅读整理_YYYYMMDD_v2.docx`、`_v3.docx`，保留已有文件。

例如生成日期为 2026 年 10 月 12 日时：

```text
西游记_阅读整理_20261012.docx
```

创建 Word 前，读取当前可用的 `documents:documents` 技能并遵循其排版、依赖运行时和渲染检查流程。导出细节见 [Word 导出与检查](references/word-export.md)。本地创建及保存属于该技能的正常工作范围，直接完成。

## 完成标准与交付

交付前确认七部分内容完整、所用书名与用户输入一致、章节范围有依据、来源链接保留、日期与保存目录正确。渲染后检查所有页面的中文字符、表格、分页与页码，修复后重新检查。

最终简短告知文件已保存，并提供已验证的 Word 文件链接或文件输出引用。中间脚本、预览图片和检查用 PDF 放入临时目录，用户另有要求时再交付。

## 调用示例

- “用读书助手整理《西游记》。”
- “随机选一本书，整理七个部分并保存为 Word。”
- “把上面整理好的《活着》阅读内容按文件名规则保存到当前工作区。”
- “使用 $reading-assistant 整理《红楼梦》，章节分析按全书阶段展开。”
